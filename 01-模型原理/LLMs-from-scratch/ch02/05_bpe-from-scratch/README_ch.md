# 从零实现字节对编码（BPE）分词器

- [bpe-from-scratch-simple.ipynb](bpe-from-scratch-simple.ipynb) / [bpe-from-scratch-simple_ch.ipynb](bpe-from-scratch-simple_ch.ipynb) 包含可选（bonus）代码，解释并展示 BPE 分词器底层原理；侧重简洁与可读性。
