# 06 - 索引与查询

## 建索引：三种常用方式

### 方式 1：一行搞定（入门首选）

```python
index = VectorStoreIndex.from_documents(documents, show_progress=True)
```

内部自动：切分 → Embedding → 写入默认内存向量库 `SimpleVectorStore`。

### 方式 2：持久化到磁盘

```python
index = VectorStoreIndex.from_documents(documents)
index.storage_context.persist(persist_dir="./storage")
```

下次启动：

```python
from llama_index.core import StorageContext, load_index_from_storage

storage_context = StorageContext.from_defaults(persist_dir="./storage")
index = load_index_from_storage(storage_context)
query_engine = index.as_query_engine()
```

**注意**：persist 保存的是索引结构 + 向量；**改 embed_model 后必须重建**。

### 方式 3：接 Qdrant（生产/与 kefu-kb 类似）

```bash
pip install llama-index-vector-stores-qdrant qdrant-client
```

```python
import qdrant_client
from llama_index.vector_stores.qdrant import QdrantVectorStore
from llama_index.core import VectorStoreIndex, StorageContext

client = qdrant_client.QdrantClient(path="./qdrant_data")  # 本地文件模式
vector_store = QdrantVectorStore(client=client, collection_name="kb")

storage_context = StorageContext.from_defaults(vector_store=vector_store)
index = VectorStoreIndex.from_documents(documents, storage_context=storage_context)

# 已有 collection 时只加载
index = VectorStoreIndex.from_vector_store(vector_store=vector_store)
```

## 查询：QueryEngine

```python
query_engine = index.as_query_engine(
    similarity_top_k=5,       # 检索 top 5 个 chunk
    response_mode="compact",  # 合成策略：compact / refine / tree_summarize
    streaming=False,
)

response = query_engine.query("7 天内如何退货？")
print(response.response)
```

### similarity_top_k 怎么调？

| 值 | 效果 |
|----|------|
| 1~3 | 精准 FAQ，噪音少 |
| 5~10 | 一般客服知识库 |
| 太大 | Prompt 超长、变慢、引入无关段落 |

### 自定义 Prompt（减少胡编）

```python
from llama_index.core import PromptTemplate

template = PromptTemplate(
    "根据资料回答。不知道就说「暂无相关信息」。\n\n"
    "资料：{context_str}\n\n问题：{query_str}\n\n回答："
)
engine = index.as_query_engine(text_qa_template=template)
```

### 看引用来源（客服系统必做）

```python
for i, sn in enumerate(response.source_nodes, 1):
    print(f"[{i}] 相关度={sn.score:.3f}")
    print(sn.node.get_content())
    print(sn.node.metadata.get("file_name", ""))
```

## 流式输出

```python
engine = index.as_query_engine(streaming=True)
streaming = engine.query("问题")
for token in streaming.response_gen:
    print(token, end="", flush=True)
```

## 异步（FastAPI 必用）

```python
# 在 async 路由里
response = await query_engine.aquery("问题")
```

同步 `query()` 会阻塞事件循环，并发高时会卡死。

```python
from fastapi import FastAPI
app = FastAPI()

@app.post("/ask")
async def ask(q: str):
    resp = await query_engine.aquery(q)
    return {"answer": str(resp), "sources": len(resp.source_nodes)}
```

## 内存索引 vs 外部向量库

| | SimpleVectorStore（默认） | Qdrant / Chroma |
|---|---------------------------|-----------------|
| 持久化 | 需 `persist()` | 自带 |
| 重启 | 需 `load_index_from_storage` | 连同一 collection |
| 规模 | 小到中等 | 大库、生产 |
| kefu-kb | — | 已用 Qdrant |
