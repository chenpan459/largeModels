# 01 - 安装与环境

## 你需要什么

| 条件 | 说明 |
|------|------|
| Python | **3.10+**（推荐 3.11） |
| 虚拟环境 | 强烈建议 `python -m venv .venv` |
| 大模型服务 | 二选一见下文 |
| 测试文档 | 几个 `.txt` 或 `.md` 文件 |

## 两种使用场景（选一种）

### 场景 A：有 OpenAI API Key（最简单）

```bash
pip install llama-index
export OPENAI_API_KEY=sk-...
```

元包 `llama-index` 自带 OpenAI LLM + Embedding，**5 行代码就能跑**（见下一篇）。

### 场景 B：本地 llama-server（本仓库推荐）

不花钱、数据不出本机，对接 `llama.cpp` 的 OpenAI 兼容 API。

```bash
pip install llama-index-core
pip install llama-index-llms-openai-like
pip install llama-index-embeddings-openai-like
pip install llama-index-readers-file   # 读 PDF 需要
```

**还需要**：至少一个跑着的 llama-server（chat + embedding），见 [07-对接llama-server.md](./07-对接llama-server.md)。

### 场景 C：没 GPU、没 API，只想练手

用 LlamaIndex 内置 **MockEmbedding**（假向量），只能验证流程，答案质量无意义：

```bash
pip install llama-index-core
```

```python
from llama_index.core import Settings
from llama_index.core.embeddings import MockEmbedding
Settings.embed_model = MockEmbedding(embed_dim=384)
# LLM 仍需配置，或使用 OpenAI
```

## 包名对照（别装错）

| 你想用的功能 | pip 包名 | import 示例 |
|-------------|----------|-------------|
| 核心框架 | `llama-index-core` | `from llama_index.core import VectorStoreIndex` |
| 元包（含 OpenAI） | `llama-index` | 同上 |
| 对接 llama-server LLM | `llama-index-llms-openai-like` | `from llama_index.llms.openai_like import OpenAILike` |
| 对接 llama-server Embedding | `llama-index-embeddings-openai-like` | `from llama_index.embeddings.openai_like import OpenAILikeEmbedding` |
| 读 PDF 等 | `llama-index-readers-file` | 增强 `SimpleDirectoryReader` |
| Qdrant 向量库 | `llama-index-vector-stores-qdrant` | `from llama_index.vector_stores.qdrant import QdrantVectorStore` |

**常见错误**：只装了 `llama-index-core`，却 `from llama_index.llms.openai_like import OpenAILike` → `ModuleNotFoundError`。

## 目录结构建议

```
~/rag_demo/
├── data/           # 放知识库文档
├── app.py          # 你的 RAG 脚本
├── storage/        # persist 后的索引（自动生成）
└── .venv/
```

## 如果安装失败

| 报错 | 处理 |
|------|------|
| `pip` 版本太旧 | `pip install -U pip` |
| 编译错误 | 优先用 Python 3.11 新 venv |
| 网络超时 | `pip install -i https://pypi.tuna.tsinghua.edu.cn/simple ...` |

更多报错见 [08-常见报错与修复.md](./08-常见报错与修复.md)。
