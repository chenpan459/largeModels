# 05 - 读文档与切分

## SimpleDirectoryReader 做什么？

**把文件夹里的文件读成 `List[Document]`**，是最常用的入门 Reader。

```python
from llama_index.core import SimpleDirectoryReader

documents = SimpleDirectoryReader(
    input_dir="./data",
    recursive=True,        # ⚠️ 默认 False，子目录不会扫
    required_exts=[".txt", ".md"],  # 可选：只读这些后缀
).load_data(show_progress=True)

print(len(documents))
print(documents[0].metadata)   # 常有 file_path, file_name
print(documents[0].text[:200]) # 正文
```

## 支持哪些格式？

| 格式 | 是否需要额外包 | 说明 |
|------|----------------|------|
| `.txt` | 否 | 直接读 |
| `.md` | 否 | 当纯文本读 |
| `.pdf` | `llama-index-readers-file` | 需 `pip install` |
| `.docx` | `llama-index-readers-file` | 同上 |
| `.csv` | 视版本而定 | 常需 file reader 包 |

PDF 读不了时：

```bash
pip install llama-index-readers-file pypdf
```

## 常见「加载 0 个文档」

| 原因 | 检查 |
|------|------|
| 路径错 | `input_dir` 是相对**当前工作目录** |
| 子目录没扫 | 设 `recursive=True` |
| 后缀被过滤 | 检查 `required_exts` |
| 目录空 | `ls ./data` |

```bash
cd ~/rag_demo && python app.py   # 确保 data 在 rag_demo 下
```

## 切分：SentenceSplitter

长 `Document` 要切成 `TextNode` 才能索引。默认用 **SentenceSplitter**：

```python
from llama_index.core.node_parser import SentenceSplitter
from llama_index.core import Settings

Settings.node_parser = SentenceSplitter(
    chunk_size=256,      # 每个 chunk 最多约 256 **token**（不是汉字数）
    chunk_overlap=32,    # 相邻 chunk 重叠，避免句子被截断
    separator="。",      # 中文可按句号切（可选）
)
```

### chunk_size 怎么选？（中文经验值）

| 文档类型 | 建议 chunk_size | 说明 |
|----------|-----------------|------|
| 短 FAQ | 128~256 | 一问一答型 |
| 政策/手册 | 256~512 | 平衡上下文与精度 |
| 长论文 | 512~1024 | 需要更多上下文 |

**默认 1024 token 对中文 FAQ 往往偏大**，检索粒度粗。

### chunk_overlap

重叠 10%~20% 的 chunk_size，避免「退货条件」被切成两半导致检索不到。

## 手动看切分效果（调试必会）

```python
from llama_index.core.node_parser import SentenceSplitter

splitter = SentenceSplitter(chunk_size=256, chunk_overlap=32)
nodes = splitter.get_nodes_from_documents(documents)

print(f"共 {len(nodes)} 个 chunk")
for i, node in enumerate(nodes[:3]):
    print(f"--- chunk {i} ---")
    print(node.get_content())
    print(node.metadata)
```

## 其他 Reader（知道即可）

| `SimpleDirectoryReader` | 本地目录 |

## 手动创建 Document（不用文件）

```python
from llama_index.core import Document

doc = Document(
    text="7 天内无理由退货。",
    metadata={"source": "manual", "category": "售后"},
)
documents = [doc]
```

metadata 可用于后面 **按类别过滤检索**（进阶）。
