# 08 - 常见报错与修复

## OPENAI_API_KEY 相关

### 报错

```
OpenAIError: The OPENAI_API_KEY environment variable is not set
或 Could not load OpenAI model...
```

### 原因

没配置 `Settings.embed_model` / `Settings.llm`，框架默认走 OpenAI。

### 修复

在 `from_documents` **之前**：

```python
from llama_index.core import Settings
from llama_index.llms.openai_like import OpenAILike
from llama_index.embeddings.openai_like import OpenAILikeEmbedding

Settings.llm = OpenAILike(..., is_chat_model=True)
Settings.embed_model = OpenAILikeEmbedding(..., model_name="...")
```

或用 OpenAI：`export OPENAI_API_KEY=sk-...`

## ModuleNotFoundError

### 报错

```
ModuleNotFoundError: No module named 'llama_index.llms.openai_like'
```

### 修复

```bash
pip install llama-index-llms-openai-like llama-index-embeddings-openai-like
```

| 缺什么 | 安装 |
|--------|------|
| openai_like LLM | `llama-index-llms-openai-like` |
| openai_like Embedding | `llama-index-embeddings-openai-like` |
| Qdrant | `llama-index-vector-stores-qdrant` |
| PDF | `llama-index-readers-file` |

## Connection refused（连接 llama-server）

### 报错

```
ConnectionError ... 127.0.0.1:8081 ... Connection refused
```

### 修复

1. 确认 llama-server 已启动：`curl http://127.0.0.1:8081/v1/models`
2. 检查 `api_base` 端口是否一致
3. 防火墙 / Docker 网络是否互通

## is_chat_model / 404 on completions

### 现象

- 404 on `/v1/completions`
- 或回答格式错乱

### 原因

`OpenAILike` 默认 `is_chat_model=False`，走了 completion 端点。

### 修复

```python
OpenAILike(..., is_chat_model=True)
```

---

## OpenAILikeEmbedding 参数错误

### 报错

```
TypeError: ... unexpected keyword argument 'model'
```

### 修复

```python
OpenAILikeEmbedding(model_name="bge-m3", ...)  # 不是 model=
```

## 加载 0 个文档

### 修复清单

- [ ] `input_dir` 路径正确（相对运行目录）
- [ ] `recursive=True` 若文件在子目录
- [ ] 文件后缀 `.txt` / `.md` 或安装 PDF reader
- [ ] `ls ./data` 确认有文件

## 答案胡编 / 与文档不符

| 可能原因 | 处理 |
|----------|------|
| 检索不到 chunk | 减小 chunk_size；增大 `similarity_top_k` |
| Prompt 太松 | 加「不知道就说暂无信息」 |
| 问法与文档措辞差 | 换问法或加同义词文档 |
| embed 模型太差 | 换 bge-m3 等专用 embedding |

调试检索：

```python
nodes = index.as_retriever(similarity_top_k=5).retrieve("你的问题")
for n in nodes:
    print(n.score, n.node.get_content()[:150])
```

## 重启后索引没了

### 原因

默认 `SimpleVectorStore` 在内存。

### 修复

```python
index.storage_context.persist(persist_dir="./storage")
# 或改用 Qdrant
```

---

## ServiceContext 报错

### 报错

旧教程里的 `ServiceContext.from_defaults(...)`

### 修复

全部改为 `Settings`（LlamaIndex 0.10+）。

---

## FastAPI 卡死 / 无并发

### 原因

在 async 路由里用了同步 `query_engine.query()`。

### 修复

```python
response = await query_engine.aquery(question)
```

---

## embedding 维度不匹配

### 现象

换 embedding 模型后 load 旧索引报错。

### 修复

删除 `storage/` 或 Qdrant collection，**重新建索引**。
