# 退换货政策

## 七天无理由退货

### 适用条件
- 签收之日起 7 天内
- 商品完好、包装齐全、配件齐全
- 不影响二次销售（未拆封数码产品、未洗涤服饰等）

### 不适用七天无理由的商品
- 定制类商品
- 鲜活易腐类
- 已拆封的音像制品、软件、数字化商品
- 贴身衣物、个人护理用品（拆封后）

## 退货流程

1. App 内打开订单 -> 申请售后 -> 选择「退货退款」
2. 填写原因并上传照片（如有质量问题）
3. 审核通过后按提示寄回（质量问题我们承担运费）
4. 仓库验收后 3-7 个工作日原路退款

## 换货流程

1. 申请售后 -> 选择「换货」
2. 审核通过后寄回商品
3. 我们发出新商品，物流单号会短信通知

## 退款时效

| 支付方式 | 到账时间 |
|----------|----------|
| 微信/支付宝 | 1-3 个工作日 |
| 银行卡 | 3-7 个工作日 |
| 对公转账 | 7-15 个工作日 |

## 质量问题

签收 15 天内发现质量问题，可申请退换货，运费由我们承担。请保留完整包装并拍照联系客服。

## 投诉与升级

若对处理结果不满意：
- App 内「我的 - 投诉建议」提交
- 或发送邮件至 complaint@yungou-mall.example.com
- 我们会在 2 个工作日内升级处理
