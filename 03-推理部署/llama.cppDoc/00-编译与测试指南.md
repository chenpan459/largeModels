## 一、编译

### 1.1 虚拟机可移植版本（推荐）

适用于 VMware / VirtualBox / KVM 虚拟机，静态链接核心库，可直接复制到其他机器运行。

```bash
cd ~/work2/largeModels/03-推理部署/llama.cpp

cmake -B build-vm \
  -DCMAKE_BUILD_TYPE=Release \
  -DBUILD_SHARED_LIBS=OFF \
  -DGGML_NATIVE=OFF \
  -DGGML_CUDA=OFF \
  -DGGML_AVX=ON \
  -DGGML_AVX2=ON \
  -DGGML_FMA=ON \
  -DGGML_F16C=ON \
  -DGGML_AVX512=OFF \
  -DLLAMA_BUILD_TESTS=OFF \
  -DLLAMA_BUILD_UI=ON

cmake --build build-vm --config Release -j$(nproc) --target llama-cli llama-server
```

### 1.1.1 启用 Web UI（必须）

Web UI 需要先下载前端资源，再编译嵌入到 `llama-server` 中。仅开启 `LLAMA_BUILD_UI=ON` 不够，还需 `tools/ui/dist/` 下有 `index.html`。

**步骤 1: 下载 UI 资源（国内用镜像）**

```bash
cd /tmp
wget -c "https://hf-mirror.com/buckets/ggml-org/llama-ui/resolve/latest/dist.tar.gz"
wget -O dist.tar.gz.sha256 "https://hf-mirror.com/buckets/ggml-org/llama-ui/resolve/latest/dist.tar.gz.sha256"

# 校验 (可选)
sha256sum -c dist.tar.gz.sha256

# 解压到 tools/ui/dist
rm -rf ~/work2/largeModels/03-推理部署/llama.cpp/tools/ui/dist/*
tar xzf dist.tar.gz -C ~/work2/largeModels/03-推理部署/llama.cpp/tools/ui/dist
ls ~/work2/largeModels/03-推理部署/llama.cpp/tools/ui/dist/index.html
```

**步骤 2: 编译（确认日志出现 `UI: using pre-built assets`）**

```bash
cd ~/work2/largeModels/03-推理部署/llama.cpp
cmake -B build-vm ... -DLLAMA_BUILD_UI=ON
cmake --build build-vm -j$(nproc) --target llama-server
```

编译成功后 `llama-server` 约 **16 MB**（无 UI 约 13 MB）。

**替代方案: npm 本地构建（需 Node.js + npm）**

```bash
cd ~/work2/largeModels/03-推理部署/llama.cpp/tools/ui
npm install
npm run build
# 产物在 tools/ui/dist/，然后重新 cmake --build
```

**产物:**

| 文件 | 路径 | 大小 |
|------|------|------|
| llama-cli | `build-vm/bin/llama-cli` | ~12 MB |
| llama-server (含 Web UI) | `build-vm/bin/llama-server` | ~16 MB |
| llama-server (无 Web UI) | `build-vm/bin/llama-server` | ~13 MB |

**与默认编译的区别:**

| 选项 | 默认 build | build-vm |
|------|-----------|----------|
| `GGML_NATIVE` | ON (`-march=native`) | OFF (通用 x86_64) |
| `BUILD_SHARED_LIBS` | ON (需 .so) | OFF (静态链接) |
| SIMD | 本机最优 | AVX2 |
| GPU | 可选 CUDA | 关闭 |

**打包复制到虚拟机:**

```bash
mkdir -p dist-vm
cp build-vm/bin/llama-cli build-vm/bin/llama-server dist-vm/
tar czf llama-cpp-vm-x86_64.tar.gz -C dist-vm llama-cli llama-server

# 复制到虚拟机
scp llama-cpp-vm-x86_64.tar.gz user@vm-ip:~/
# 虚拟机内
tar xzf llama-cpp-vm-x86_64.tar.gz && chmod +x llama-cli llama-server
```

**虚拟机要求:**

- 系统: Linux x86_64 (Ubuntu 20.04+)
- CPU: 支持 AVX2 (`grep avx2 /proc/cpuinfo` 有输出)
- 内存: >= 4 GB
- 无需 GPU

## 二、模型下载

**重要:** 不要使用 `-hf` 在线下载启动 server，网络不通时会长时间无日志。先下载模型到本地，再用 `-m` 指定路径。

### 2.1 安装下载工具

```bash
pip install huggingface_hub
export PATH="$HOME/.local/bin:$PATH"

# 持久化 PATH 和镜像 (国内必加)
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
echo 'export HF_ENDPOINT=https://hf-mirror.com' >> ~/.bashrc
source ~/.bashrc

# 验证 (新版用 hf，huggingface-cli 已弃用)
hf --help
```

安装位置:
- Python 包: `~/.local/lib/python3.10/site-packages/`
- 命令行: `~/.local/bin/hf`

查看仓库内有哪些文件（下载前可先 `--dry-run`）:

```bash
export HF_ENDPOINT=https://hf-mirror.com
hf download Qwen/Qwen2.5-7B-Instruct-GGUF --dry-run
```

---

### 2.2 模型选型

| 模型 | 参数量 | Q4_K_M 大小 | 内存需求 | 适用场景 |
|------|--------|------------|----------|----------|
| SmolLM-135M-Instruct | 135M | ~105 MB | >= 2 GB | 验证编译/跑通流程 |
| Qwen2.5-0.5B-Instruct | 500M | ~469 MB | >= 4 GB | 日常对话（推荐 VM） |
| Qwen2.5-7B-Instruct | 7B | ~4.7 GB | >= 8 GB | 高质量对话（需大内存） |

说明:
- SmolLM-135M **不是数学模型**，只是通用小模型，回复质量差，仅适合测试
- Qwen 系列为阿里通义千问，中文/英文对话效果远好于 SmolLM
- 7B 模型在官方仓库中为**分片文件**（2 个 .gguf），需全部下载且放在同一目录

```bash
./build-vm/bin/llama-cli \
  -m ~/models/qwen2.5-0.5b/qwen2.5-0.5b-instruct-q4_k_m.gguf \
  -co -cnv \
```

```bash
./build-vm/bin/llama-cli \
  -m ~/models/qwen2.5-7b/qwen2.5-7b-instruct-q4_k_m-00001-of-00002.gguf \
  -co -cnv \
```

参数说明:
- `-co -cnv`: 对话模式（Qwen 官方推荐）
- `-p "..."`: Qwen 系统提示词
- `-t N`: CPU 线程数
- `-n N`: 最大生成 token 数

## 五、常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| server 启动无输出 | `-hf` 在线下载卡住 | 改用 `-m 本地路径`，加 `--verbose` |
| curl Connection refused | server 未启动完成 | 等待 `HTTP server is listening` |
| hf download 网络不可达 | VM 无法访问 huggingface.co | 用 `HF_ENDPOINT=https://hf-mirror.com` 或 wget |
| File not found in repository | 7B 模型文件名不对 | 7B 为分片文件，见 2.5 节 |
| Repository not found | 仓库名错误 | SmolLM 用 `second-state/...`，Qwen 用 `Qwen/...` |
| huggingface-cli 弃用 | 新版改用 hf | 用 `hf download` 代替 |
| Illegal instruction | VM 不支持 AVX2 | 用 1.4 保守编译 |
| 回复内容乱/数学公式 | SmolLM 太小 (135M) | 换 Qwen2.5-0.5B 或 7B |
| 7B 加载失败 | 分片不完整 | 两个 .gguf 必须在同一目录 |
| 7B 运行很慢/内存不足 | 模型太大 | 换 0.5B，或增加内存到 16 GB |
| 动态库版本找不到 .so | 未设置 LD_LIBRARY_PATH | 见 1.2 节，或直接用 build-vm 静态版 |
| localhost:8080 打不开 | 编译时未嵌入 Web UI | 见 1.1.1 节，下载 dist 后重编 llama-server |
| 编译警告 no assets available | UI 资源缺失 | 下载 dist.tar.gz 到 tools/ui/dist/ |

## 六、命令速查

### 完整流程（推荐 Qwen2.5-0.5B）

```bash
# 1. 下载 Web UI 资源并编译
cd /tmp
wget -c "https://hf-mirror.com/buckets/ggml-org/llama-ui/resolve/latest/dist.tar.gz"
tar xzf dist.tar.gz -C ~/work2/largeModels/03-推理部署/llama.cpp/tools/ui/dist

cd ~/work2/largeModels/03-推理部署/llama.cpp
cmake -B build-vm -DCMAKE_BUILD_TYPE=Release -DBUILD_SHARED_LIBS=OFF \
  -DGGML_NATIVE=OFF -DGGML_CUDA=OFF -DLLAMA_BUILD_TESTS=OFF -DLLAMA_BUILD_UI=ON
cmake --build build-vm -j$(nproc) --target llama-cli llama-server

# 2. 下载模型
export HF_ENDPOINT=https://hf-mirror.com
export PATH="$HOME/.local/bin:$PATH"
mkdir -p ~/models/qwen2.5-0.5b
hf download Qwen/Qwen2.5-0.5B-Instruct-GGUF \
  qwen2.5-0.5b-instruct-q4_k_m.gguf \
  --local-dir ~/models/qwen2.5-0.5b

# 3. 启动服务
pkill llama-server
./build-vm/bin/llama-server \
  -m ~/models/qwen2.5-0.5b/qwen2.5-0.5b-instruct-q4_k_m.gguf \
  --host 0.0.0.0 --port 8080 -t 4 --parallel 4 --ui --verbose

# 4. 测试
curl http://localhost:8080/health
curl http://localhost:8080/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"你好"}],"max_tokens":128}'
# 浏览器: http://localhost:8080
```
