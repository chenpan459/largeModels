## 常用命令

```bash
# 安装
pip install vllm

# 基础服务（默认 V1）
vllm serve meta-llama/Llama-3.2-3B --host 0.0.0.0 --port 8000

# 2 卡 TP
vllm serve Qwen/Qwen2.5-7B-Instruct -tp 2

# AWQ 量化
vllm serve model --quantization awq

# 高并发
vllm serve model --max-num-seqs 256 --max-num-batched-tokens 8192 \
  --gpu-memory-utilization 0.95 --enable-prefix-caching

# 调试
VLLM_LOGGING_LEVEL=DEBUG vllm serve model --enforce-eager --max-num-seqs 4

# 强制 V0
VLLM_USE_V1=0 vllm serve model

# Python API
python -c "
from vllm import LLM, SamplingParams
llm = LLM(model='meta-llama/Llama-3.2-3B')
print(llm.generate(['Hello'], SamplingParams(max_tokens=16))[0].outputs[0].text)
"
```

## 环境变量

| 变量 | 默认 | 用途 |
|------|------|------|
| `VLLM_USE_V1` | **True** | V0/V1 选择 |
| `VLLM_ENABLE_V1_MULTIPROCESSING` | True | 同步 LLM 子进程 |
| `VLLM_ATTENTION_BACKEND` | - | 强制 attention backend |
| `VLLM_USE_FLASHINFER_SAMPLER` | - | FlashInfer top-k/top-p |
| `VLLM_LOGGING_LEVEL` | INFO | DEBUG/INFO/WARNING |
| `VLLM_MLA_DISABLE` | False | 禁用 MLA |
| `VLLM_ALLOW_RUNTIME_LORA_UPDATING` | False | 热更新 LoRA |
| `CUDA_VISIBLE_DEVICES` | - | 可见 GPU |

## API 速查

```bash
# Chat
curl http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"model","messages":[{"role":"user","content":"hi"}]}'

# 健康检查
curl http://localhost:8000/health

# 模型列表
curl http://localhost:8000/v1/models

# LoRA 加载
curl -X POST http://localhost:8000/v1/load_lora_adapter \
  -H "Content-Type: application/json" \
  -d '{"lora_name":"my_lora","lora_path":"/path/to/adapter"}'
```
